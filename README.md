# Task Management App

A full-stack task management web application built with the MERN stack (MongoDB, Express, React, Node.js) for my GoMyCode Lab Phase project.

## Planned Features
- User registration and login
- Create, edit, delete tasks
- Task status: to-do / in progress / done
- Filter and search tasks

## Tech Stack
React, Node.js, Express, MongoDB

Draft: Lab Phase
